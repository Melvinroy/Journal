## Phase 1 — Plan the product ✅

### Product decisions

- ✅ **Product decision:** Build for your own Windows 11 computer first, using the same setup future users will follow. Other operating systems are later work.
- ✅ **Product decision:** Offer Trading and Journal as selectable views of one trading module and one shared record of trades. Hiding Journal must never stop recording.
- ✅ **Product decision:** Reuse the existing planner, Positions, Journal, calculations, saved-plan checks and protection logic. Add new screens only for setup, connection and local-app management.
- ✅ **Product decision:** Open the app in a local browser from a Windows launcher. A desktop rewrite is not part of this first version.
- ✅ **Product decision:** Keep app sign-in and private trading records local. The public GitHub page will provide the download and instructions, not hold the private ledger.
- ✅ **Product decision:** Sign in to IBKR through TWS, confirm the exact paper account, and require review and confirmation before a trade. Opening a connection must never place an order.
- ✅ **Product decision:** Start with one-command installation as the goal, while clearly guiding any official IBKR software or TWS setup that still needs you.
- ✅ **Product decision:** Keep unsupported trading choices locked. Qualify paper trading first, then make separate decisions about personal live use and a public release.
