# Trading Journal

A calm, modern trading journal for reviewing performance, execution quality, trading psychology, and the repeatability of your edge.

## First iteration

- Responsive overview dashboard
- Net P&L, win rate, profit factor, and discipline metrics
- Equity-curve visualization and setup-performance insights
- Recent-trade journal with execution grades and R-multiples
- Working trade-entry form with browser-local persistence
- Automated GitHub Pages deployment

## Run locally

```bash
npm install
npm run dev
```

## Product direction

The app is designed as a decision cockpit: quick to log, calm to review, and focused on behavior—not just P&L.
